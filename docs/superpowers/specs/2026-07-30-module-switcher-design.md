# 模块切换器设计

## 目标

为全屏个人网站提供可见、可点击的模块切换器：桌面端固定在右侧，移动端改为底部横向导航。

## 行为

- 桌面端显示五个纵向模块链接：首屏、能力、技术范围、项目、联系。
- 移动端显示相同链接的固定底部横向导航，文字使用短标签。
- 点击链接使用现有页面平滑滚动到对应锚点；不依赖 JavaScript 也可正常跳转。
- `IntersectionObserver` 根据当前视口中的模块切换 `is-current` 状态。
- 当前模块具有明确的颜色与尺寸状态，非当前模块保持低对比度但可点击。
- 移动端导航避开系统安全区域，并提供足够的触控尺寸。

## 实现边界

- 在 `index.html` 新增一个语义化 `nav`，使用锚点链接，不改变现有顶部导航。
- 在 `app.js` 复用观察器能力，为模块链接同步当前状态；不添加高频滚动事件。
- 在 `styles.css` 使用媒体查询切换右侧轨道与底部横向导航。
- 启用减少动态效果时，保留状态高亮和锚点跳转，不使用额外位移动画。

## 验收标准

1. 桌面端在右侧显示五个模块切换入口，并能切换到对应模块。
2. 移动端在底部显示横向导航，当前模块高亮且不会遮挡内容。
3. 上下滚动时当前状态随模块变化，重复进入模块不会留下多个高亮入口。
4. 锚点链接、键盘焦点和减少动态效果降级均可用。
5. 页面脚本语法与现有布局、首屏动画契约测试通过。
