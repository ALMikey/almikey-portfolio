# 首屏重入动画设计

## 目标

让首屏与其余模块一样，在首次加载和从下方滚回顶部时重复播放进入动画，同时不引入强制滚动、背景裁切或高频滚动计算。

## 行为

- 首次加载时，首屏按固定顺序显示：背景遮罩、身份标签、名称、职业与简介、操作按钮、右下状态信息。
- 首屏离开视口后移除活动状态；重新进入视口时恢复同一顺序的动画。
- 其余模块保留现有的重复进入逻辑，不改变模块高度、背景蒙版或滚动方式。
- 系统启用“减少动态效果”时，首屏内容直接显示，不执行动画。

## 实现边界

- 使用现有的 `IntersectionObserver`，不新增动画框架或网络依赖。
- 使用仅影响合成层的 `opacity` 与 `transform` 动画。
- 不对背景图片做缩放或滚动位移，避免与完整背景呈现和滚动性能要求冲突。
- 首屏状态通过单一 `hero-active` 类控制；离开视口时移除，进入时添加。

## 验收标准

1. 初次加载时首屏内容按顺序渐入。
2. 滚动离开首屏后再滚回顶部，动画完整重播。
3. 连续上下滚动不会累积动画类、造成闪烁或留下隐藏内容。
4. `prefers-reduced-motion: reduce` 下首屏始终可见。
5. 页面脚本语法检查和布局回归测试通过。
